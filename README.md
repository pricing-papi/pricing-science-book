# Pricing Science – book site

Sales page (`/`) and post-purchase page (`/thanks/`) for *Pricing Science* by Tom Selameab, CPP. Static HTML, deployed on Netlify at book.curlysconsulting.com.

- Checkout: Stripe payment link, which redirects to `/thanks/?session_id=...`
- Tracking: X pixel `qmxf6`; Purchase event `tw-qmxf6-qmxf7` fires on `/thanks/`
